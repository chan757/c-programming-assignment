문제 1. (구조체 배열)
다음은 5명의 이름과 나이를 저장하는 구조체 배열을 선언하고, 4번째 요소(인덱스 3)의 멤버에 값을 저장하는 코드이다. 빈칸 (가)와 (나)에 들어갈 코드로 알맞은 것은?

#include <stdio.h>
#include <string.h>

struct Person {
    char name[50];
    int age;
};

int main() {
    (  가  ) people[5];
    strcpy((  나  ), "Moon");
    people[3].age = 21;
    return 0;
}

1) (가): Person / (나): people.name[3]
2) (가): struct Person / (나): people[3].name
3) (가): struct Person / (나): people[3]->name
4) (가): Person / (나): people[3].name

문제 2. (구조체 포인터와 동적 할당)
다음은 malloc() 함수를 이용해 5명의 Person 구조체 메모리를 동적 할당하고, 첫 번째 요소의 멤버에 접근하여 출력하는 코드이다. 빈칸 (가)와 (나)에 들어갈 코드로 알맞은 것은?

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

struct Person {
    char name[50];
    int age;
};

int main() {
    struct Person* p;
    p = (struct Person*)malloc(5 * sizeof(struct Person));
    
    strcpy((  가  ), "Moon");
    (  나  ) = 25;
    
    printf("Name: %s, Age: %d\n", p->name, p->age);
    free(p);
    return 0;
}

1) (가): p.name / (나): p.age
2) (가): *p.name / (나): *p.age
3) (가): p->name / (나): p->age
4) (가): p->name / (나): *p->age

문제 3. (구조체와 함수)
다음 C 프로그램의 실행 결과로 알맞은 것은?

#include <stdio.h>
#include <string.h>

struct Person {
    char name[50];
    int age;
};

void updateAge(struct Person p) {
    strcpy(p.name, "Yun");
    p.age = 22;
}

int main() {
    struct Person p1 = { "Moon", 25 };
    updateAge(p1);
    printf("Name: %s, Age: %d\n", p1.name, p1.age);
    return 0;
}

1) Name: Moon, Age: 25
2) Name: Yun, Age: 22
3) Name: Moon, Age: 22
4) Name: Yun, Age: 25

문제 5. (열거형)
다음 코드에서 enum으로 정의된 열거형 상수 Green의 정수 값과 프로그램의 출력 결과로 옳은 것은?

#include <stdio.h>

enum TrafficLight {
    Red,
    Yellow,
    Green
};

int main() {
    enum TrafficLight signal = Green;
    switch (signal) {
        case 0: printf("Stop\n"); break;
        case 1: printf("Caution\n"); break;
        case 2: printf("Go\n"); break;
        default: printf("Unknown\n"); break;
    }
    return 0;
}

1) Green의 값: 0, 출력 결과: Stop
2) Green의 값: 1, 출력 결과: Caution
3) Green의 값: 2, 출력 결과: Go
4) Green의 값: 3, 출력 결과: Unknown
